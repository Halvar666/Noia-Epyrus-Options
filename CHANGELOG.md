# Changelog

## 1.0.0rc1 — 2026-09-03

First public release candidate.

- Ported Noia Fox Options to Epyrus 2.2.1.
- Added Grey, Blue and Black Noia color schemes.
- Added default/Australis, classic square and classic rounded mail-tab styles.
- Added standard, square and rounded dialog-tab variants.
- Added rounded dialog buttons and blue close buttons.
- Restored classic Noia striped message rows.
- Added primary-toolbar border, toolbar hover-background and plain-toolbar options.
- Added Linux- and Windows-specific Black-theme integration.
- Fixed Add-ons Manager contrast and details-link styling in Black mode.
- Fixed Linux AppMenu text contrast in Black mode.
- Fixed Windows caption glyphs in Black mode with the Menu Bar hidden.
- Cleaned superseded development CSS and source comments.
