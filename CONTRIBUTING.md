# Contributing

Noia Epyrus Options targets Epyrus and the Noia Epyrus complete theme.

When submitting changes:

- preserve compatibility with Epyrus 2.2.1 unless compatibility is intentionally updated;
- test Linux GTK3 and Windows behavior when modifying shared UI CSS;
- do not reintroduce old Firefox titlebar/Australis window-frame logic;
- keep Windows titlebar and AppMenu geometry under native Epyrus control;
- prefer narrowly scoped selectors over global XUL overrides;
- preserve upstream license notices and attribution for inherited files.
